RailNav — поиск маршрутов по железной дороге в Германии и Европе: карта всех вариантов, поездки через несколько городов, туда-обратно, офлайн-расписание, уведомления о пересадках. Исходный код: github.com/QwertyQwertovich/railnav.

Данные маршрута хранятся только в самой ссылке (после «#») и никуда не отправляются.
