# RailNav

Android-приложение (Kotlin + Jetpack Compose) для поиска маршрутов, прежде всего по железной дороге.

## Источники данных (Настройки → Источник расписаний)
- **Transitous** (MOTIS 2, вся Европа, открытые данные): по умолчанию. Реалтайм есть там, где его отдают операторы.
- **Deutsche Bahn (bahn.de)**: неофициальный API сайта. Точные платформы и реалтайм DB, но bahn.de может временно блокировать запросы (`OPS_BLOCKED`).
- **Офлайн**: GTFS с gtfs.de (DB дальнее + региональные поезда, ~15 МБ архив → ~58 МБ на устройстве), маршрутизация алгоритмом Connection Scan на телефоне. Если включено «без сети использовать офлайн», приложение переключается само.

## Возможности
- Фильтр по видам транспорта в отдельном окне (ICE, IC/EC, ночные, RE, RB, S-Bahn, U-Bahn, трамвай, автобусы, паромы). RE и RB различаются по названию линии.
- Векторная карта (MapLibre + OpenFreeMap) со всеми вариантами сразу; тап по линии выделяет вариант.
- Промежуточные точки с мин./макс. стоянкой, строгий или свободный порядок; туда-обратно (можно без «Куда»: разворот в последнем городе) с возвратом «рано / не раньше / как можно позже».
- Избранные станции и города (☆ в выборе места), избранное время отправления («ближайшее воскресенье 05:00»).
- Режим «Путешествие»: только старт и города для посещения, маршрут возвращается в старт.
- Табло станции: отправления и прибытия с реальным временем и платформами.
- Живое время рядом с плановым (✓ — по расписанию), раздельные прибытие/отправление на остановках.
- Конкретная станция или «любой вокзал города».
- Сохранение поездок, уведомления (отправление, прибытие, пересадка, платформа, «пересадка под угрозой»), фоновое обновление реалтайма раз в 15 минут.
- «Опоздание / отмена → альтернативы» для каждого поезда.
- «Поделиться»: только ссылка / кратко / подробно, текст можно поправить. Ссылка ведёт на страницу
  https://qwertyqwertovich.github.io/railnav/ — маршрут хранится в самой ссылке (после `#`), оттуда его можно открыть в приложении или скачать APK.

## Скачать
Актуальный APK: https://github.com/QwertyQwertovich/railnav/releases/latest/download/RailNav.apk

## Сборка
```
./gradlew :app:assembleDebug
```
Нужен JDK 17 (переменная `JAVA_HOME` или Android Studio). Тесты на реальных данных:
```
./gradlew :app:testDebugUnitTest -Dgtfs.dir=<папка с fv.zip/rv.zip> -Donline=true
```

Данные: Transitous / MOTIS, gtfs.de (CC BY 4.0), © OpenStreetMap contributors.
